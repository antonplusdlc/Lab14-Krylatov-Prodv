# ПР14. Ответы на контрольные вопросы

1. AppendAllText дописывает в конец файла не перезаписывая его.
2. string[]. каждая строка - элемент массива.
3. данные могут остаться не записанными в файл, а файловые ресурсы - занятыми.
4. по смыслу аналогично конструкции try-finally.
5. Path.Combine надежнее. он сам правильно обьединяет путь с учетом правил ос. в ручную можно совершить ошибку.
6. FileNotFoundException - файл не найден, IOException - ошибка ввода-вывода.
